Politique de Confidentialité

Dernière mise à jour : 14 septembre 2026

Bienvenue sur NicheInsight Studio. La protection de vos données et le respect de votre vie privée sont au cœur de nos priorités. Cette politique explique comment nous traitons les informations dans le cadre de notre outil d'analyse.

1. Collecte des données

NicheInsight Studio ne collecte directement aucune donnée personnelle identifiable auprès des visiteurs de ce site. Nous exploitons exclusivement des API publiques pour analyser les tendances de marché et les contenus visuels à des fins d'étude e-commerce.

2. Utilisation des API tierces

Notre application interagit avec des API tierces (notamment Pinterest) pour extraire des métriques publiques anonymisées. Aucune donnée d'utilisateur privé n'est stockée, revendue ou partagée avec des tiers.

3. Fichiers journaux et Cookies

Ce site est hébergé via GitHub Pages. GitHub peut collecter des journaux de serveur de base (adresse IP, type de navigateur) à des fins de sécurité et de maintenance du service.

4. Contact

Pour toute question concernant cette politique ou nos outils, vous pouvez nous contacter via notre dépôt officiel : GitHub Repository.
